# Neon Arcade — GitHub Pages Gaming Site

> Generated by **Gaming Website Structure Builder**.
> 100% original template — no copied images, logos, text, links or game files.

## Project structure

```
/
  index.html      <- page shell (never edit)
  style.css       <- design (never edit)
  script.js       <- renders everything from games.json (never edit)
  games.json      <- YOUR DATA: the game list (edit this)
  README.md
/images/
  placeholder.jpg <- shown automatically when an image is missing
```

## How to add a game (the only workflow you need)

1. Upload the game's JPG image into the `/images` folder (e.g. `images/neon-drift.jpg`).
2. Add an entry to `games.json`:

```json
{
  "title": "Game Title",
  "image": "images/neon-drift.jpg",
  "url": "https://example.com/game",
  "category": "Action",
  "featured": true,
  "trending": false
}
```

3. Commit to GitHub. The site updates automatically — `index.html`,
   `style.css` and `script.js` never need to change.

## Field reference (games.json)

| Field      | Required | Meaning                                          |
|------------|----------|--------------------------------------------------|
| title      | yes      | Name shown on the card                           |
| image      | yes      | Path to the JPG in /images                       |
| url        | yes      | Where the card links when clicked                |
| category   | yes      | Used to build the category filter automatically  |
| featured   | no       | true => appears in the Featured section          |
| trending   | no       | true => appears in the Trending section          |

## Deploy to GitHub Pages

1. Create a new GitHub repository.
2. Upload all files from this ZIP (keep the `images/` folder).
3. Repository **Settings -> Pages -> Source: main branch / root** -> Save.
4. Your site is live at `https://<username>.github.io/<repo>/`.

## Features

- Mobile & desktop responsive
- Live search + automatic category filtering
- Featured / Trending sections driven by flags in games.json
- SEO meta tags, lazy-loaded images, no dependencies — fast loading
